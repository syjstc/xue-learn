# Language Learning

## Map design

- Organize milestones around communicative functions and situations, not isolated grammar lists.
- Recycle vocabulary and forms across increasingly varied contexts.
- Progress from comprehensible input and controlled production to guided and independent communication.
- Include pronunciation, listening, literacy, or writing only when relevant to the learner's goal.

## Unit teaching

- Use this compact content grammar: situation and communicative intention → natural dialogue or text → noticing → meaning, form, pronunciation, and pragmatics as relevant → focused contrast → controlled production → guided dialogue → new-situation role-play or authentic written response → selective correction and retry.
- Present each dialogue as a standalone `conversation` block, separate from setup and analysis. Put every speaker turn in its own structured `turns` item with `speaker` and `text`; never flatten turns into prose, a callout, or inline separators.
- Use ordinary `stage` subviews for focused correct/incorrect, literal/natural, or form/meaning contrasts. Use `callout` for a concise definition, pronunciation cue, or high-value pitfall; use headings and paragraphs for the connective explanation.
- Make learners notice the target in context before explaining it. Keep grammar subordinate to the communicative goal rather than building an isolated rule list.
- For Japanese, annotate learner-facing kanji with furigana ruby so beginners can read dialogue and examples without leaving the communicative flow; prefer group readings on words/compounds, not per-character annotations.

## Scenario theater

- Make the learner accomplish a genuine communicative task in the language being learned: obtain information, negotiate, repair misunderstanding, persuade, coordinate, or write for a real audience.
- Keep character dialogue and learner-facing choice labels primarily in the target language. Use the learner's known language only for essential beginner support; do not translate every line or let translation replace comprehension.
- Make choices express the actual utterance or message the learner would use, not labels such as “use the polite form” or “choose the correct tense.”
- Build consequences from meaning and pragmatics: what the other person understood, how natural or appropriate the register felt, whether the task advanced, and whether clarification was needed.
- Recycle target vocabulary and forms across changed speakers, intentions, registers, and pressures. Include natural repair moves when misunderstanding occurs.
- Match linguistic complexity to the learner: short high-frequency language and useful frames for beginners; ambiguity, idiom, register, and spontaneous reformulation for advanced learners.
- For Japanese theater dialogue, keep furigana on new or hard kanji so choices stay readable without translating the whole line.

## Practice and evidence

- Recognition alone does not demonstrate productive ability.
- When a target promises speaking or writing, require contextualized production; a recognition check cannot replace it.
- Use server-owned components and checks for bounded practice, then use material follow-up for open production, feedback, and retry.
- Use a meaningfully new situation for transfer rather than reusing the model dialogue.
- Correct selectively: preserve what is already correct, identify the highest-value pattern, model a more natural response, and ask the learner to retry.

## Adaptation

- Keep input understandable but slightly beyond the learner's demonstrated level.
- Give beginners sentence frames and constrained choices; fade them as fluency and independence improve.
- For Japanese literacy scaffolding, use furigana heavily for beginners and early intermediates; leave known high-frequency readings bare and annotate only new or difficult kanji as reading independence grows.
