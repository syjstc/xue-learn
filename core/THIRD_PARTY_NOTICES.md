# Third-party materials

Third-party code, fonts and other dependencies retain their own copyright and
license terms. XueLearn's MIT license does not replace those terms. Preserve the
applicable notices when redistributing those components.

`package.json` and `pnpm-lock.yaml` identify the versions used to build Core.
Consult each package's license and notices, including dependencies bundled into
the JavaScript entries. Type declarations and packaged source imports do not
transfer ownership of third-party code to XueLearn.

Desktop artwork, installer icons and the Kenney desk model are not included in
this Core repository. Their notices remain with the products that distribute
them. This file is not a completed audit of every transitive dependency.

Report missing attribution or permission questions to `contact@xue-learn.com`.
