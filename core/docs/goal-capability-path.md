# 全程能力契约与 Goal 生成

新建完整 Goal 时，先确定目标与成果，再分段规划全部模块和单元的能力契约，最后统一合并校验。正文、题目和详细 KACOM 定义仍按需生成。已有课程不自动重规划。

## 契约与 KACOM

`GoalMapPlan.learningPath` 是计划元数据，复用 KACOM 的 `atom / concept / skill / competency` 身份和七个认知维度。它不创建另一套掌握度，也不写学习证据。

- `entities`：稳定的 `semanticKey`、类型、名称、描述和适用范围。
- `baseline`：外部入门条件，只允许自述或未知；不能由规划模型宣称已经验证。
- `goal.outcomes`：与已确认的 `o_N` 成果一一对应的要求，以及最终综合任务。
- `modules`：入口、出口、检验方式、衔接说明及全部单元。
- `units`：入口、产出、支持的模块能力、检验任务、允许的辅助程度和情境距离。
- 每个入口指向 `baseline` 或准确的先前 `u_N_N` 单元，并声明所需维度和门槛。多个入口表示同时需要；路线可以分支和汇合。

目标中的“门槛”是教学要求，不是用户的当前分数。相同语义身份在模块和后续单元发布时使用同一个 KACOM 实体；规划身份采用 Goal 内的 `path:<semanticKey>` 稳定键，数据库 ID 仍由宿主管理。

## 检查边界

确定性校验覆盖：身份重复、未知引用、自己或未来单元依赖、缺失基础、来源产出不足、认知维度或门槛不足、跨模块能力未导出、隐藏入口、模块出口没有单元提供、成果缺口，以及迁移和独立性对应的任务条件。

检查通过表示声明的路线在入门假设成立时闭合。它不能证明教学必然有效，也不能证明描述的任务足够真实或用户已经掌握。实际任务质量仍需要教学审核和学习证据。模型写出含糊的能力或漏报前置知识，不能仅靠图结构检查发现。

保存和重新读取均走相同的契约校验。失效的契约不能静默回退为自由生成。既有无契约课程继续走原有流程。

## 生成与交互

1. 目标方向和成果先显示，随后实时显示模块及已形成的单元数量。
2. 所有规划模式都有阶段活动和等待反馈；不伪造百分比或预计完成时间。
3. 确认页可展开单元入口、产出、来源和检验任务。基础列表的“这项基础还不会”会带着明确反馈重新规划补桥，并重新校验整条路线。
4. 自动创建模式遇到未知入门基础时复用计划确认卡，模块尚未发布。用户已选择无需提问时自动继续。
5. 模块骨架直接从契约生成，省去每个模块重复编写能力和单元目录的模型调用。现有课程审核仍保留；审核要求更改已确认路线时，必须修订路线，不能偷偷改成另一套单元。
6. 单元详细 KACOM 生成时，保留语义身份、类型、入口/出口维度和门槛。目标前缀开放之前及完整图发布之前均检查；前缀偏离可做一次受约束修复。
7. 模块草稿可以乱序完成。Desktop 发布后将契约中的单元引用绑定为真实 ID，并再次协调跨模块依赖；独立单元不会因导航顺序被强行串联。

审核指出具体内容缺口时，只修订被标记模块的路径契约，保留现有语义身份、模块出口的全部维度与门槛、既有单元引用和产出；新增课时追加在后，避免破坏后续依赖。每次修订都校验完整路线，再从修订后的契约投影草稿。未通过的模块不会发布，正常模块草稿保留。整份目录重新审核通过后，Desktop 在同一事务中保存目标路线与被修订模块的 brief，再发布课程。旧版本重试留下的嵌套错误会还原为原始审核意见，不再把错误字符串反复包裹后拒绝重试。

## 分段生成、恢复与缓存

持久化 Goal authoring 先提交模块摘要，再提交共享能力身份、入门基础、目标成果和模块出口，随后按先后依赖逐个提交模块的单元契约。每段立即校验并保存检查点；后段失败时，重试复用已通过的目标身份和各段，只重做失败段。用户更改已确认目标契约会使这些检查点失效。

各路径段始终使用同一个 `commit_goal_path_part` 工具、相同的工具 Schema 和工具选择。长资料留在既有对话前缀中，后续只追加当前段要求及结果，不反复发送全文。这样保持可缓存前缀稳定；实际命中仍以模型服务返回的 cache read token 为准。

模块段仍使用普通单次输出额度。每段检查前置来源、模块出口及单元契约，最终段检查全部成果闭合，通过后由程序合并成完整 `learningPath` 并建立后续模块分支点；不再要求模型重新输出完整计划。

## 本次交付范围

Core 契约、规划、生成校验，以及 Desktop 的 SQLite 发布和计划界面。Platform、Video、Game 使用各自固定的 Core 包，本次未升级它们。

数据库采用现有计划/模块 JSON 字段，无新增掌握度表，也不重写已有课程、练习、证据或学习进度。

掌握度估计只在 [评估模型提案](mastery-estimation-proposal.md) 中规划，尚未实现。
