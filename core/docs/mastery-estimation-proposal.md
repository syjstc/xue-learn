# KACOM 实时掌握度估计提案

状态：设计提案，未实现、未经过数据校准。下列参数用于讨论和试验，不应直接成为生产评分规则。

目标是让用户大致了解自己“在什么条件下能做到什么”，并知道这个估计有多少证据支持。显示百分比，但不把阅读完成率当成掌握度。

## 表达对象

最小状态为 `学习者 × KACOM 实体 × 认知维度 × 任务情境/辅助条件`。复用现有 KACOM 实体 ID、LearningTarget 要求和证据事件，不新建平行能力体系。

每个估计同时携带：

- 掌握估计：在契约规定的条件下满足判据的估计水平，显示为整数百分比。
- 估计区间和证据置信程度：与百分比独立，不能把“证据不足”显示成“能力很低”。
- 证据覆盖：哪些必需维度和任务条件已被观察，哪些未知。
- 最近证据、样本来源和未达成的关键要求。

没有有效证据时显示“待评估”，不显示 0%。阅读、停留时间、点开解释和完成导航只影响学习活动记录。自述基础可影响诊断优先级，不能伪装成测试证据。

示例：`掌握估计约 72% · 证据较少 · 已观察 3/5 项要求`。满足覆盖与独立性条件后才使用“已达标”；85% 的平均值不能掩盖一个尚未通过的关键要求。

## 证据事件

每条事件至少记录稳定 event ID、学习者、实体、维度、对应判据、题目/任务家族、难度、情境距离、提示程度、作答次数、结果或判据得分、评分方法/版本和发生时间。

选择题主要支持记忆和理解；应用能力需要实际操作或解题表现；迁移需要新的远情境任务；独立性只由无辅助表现支持；流畅性还需要准确率与合理时间窗；稳定性需要跨时间观察。不能从某一维度直接推出另一维度。

同题重答、看答案后作答、同一任务的多个高度相关判据不能当成多个独立证据。用任务家族去重、单任务权重上限和提示折扣控制重复计数。一次失败也要结合题目质量和情境，不立即抹去此前全部证据。

## 初始估计器候选

先做透明、可重放的加权 Beta 证据累积基线，再用留出任务检验是否需要更复杂模型。

对可比较的实体、维度和任务条件维护 `α、β`。每条证据的判据结果为 `y ∈ [0,1]`，权重为 `w`：

```text
α' = α + w × y
β' = β + w × (1 − y)
候选估计 = α' / (α' + β')
```

`w` 由评分可靠性、与目标难度的匹配、提示程度、事件独立性和证据时效共同约束。先验可以从弱信息先验开始，但先验均值不直接呈现为用户分数。没有足够覆盖时，仍输出“待评估”。

这是一个可校准的工程基线，不意味着权重分数已经是严格的成功概率。只有在独立任务上完成校准后，才能对用户使用概率式解释。复杂任务不能直接套用选择题的权重或难度。

时间因素先采用“置信区间变宽、建议复查”的方式。若之后加入衰减，应让证据贡献逐步回到先验，并按维度和任务类型校准；不能把长期未打开应用机械地变成能力归零。

## 从实体到目标

LearningTarget 直接读取契约指定的实体、维度和门槛。每个必需要求独立判断；关键门槛不可由其他高分抵消。

模块和 Goal 分为两个输出：

1. 描述性的整体估计：对已具备足够证据的要求按显式权重汇总，并同时展示证据覆盖和区间。覆盖不足时不提供一个貌似完整的百分比。
2. 达标状态：所有关键门槛均有适当任务证据、所需维度覆盖充分，并且独立性/迁移等条件满足后，才标记达标。最终综合任务必须直接提供证据，不能只看组成技能的平均值。

同一个 KACOM 实体在多个课程出现时复用证据，但只在范围和条件相容时迁移。更难或更陌生的目标不能直接继承旧分数。预备知识可支持“可以开始学”的判断，不等于已掌握后续综合能力。

## 实时更新和交互

由已有证据事件触发幂等重算，发布带估计版本的状态更新。界面展示估计变化的可解释原因，例如“刚完成一次无提示的相近情境任务”。撤销事件、修订判据或更新估计器后能够完整重放。

用户可展开查看已观察的维度、证据新鲜度和下一项有用的验证任务。优先补最影响路线判断的证据，不为了刷新百分比频繁打断学习。

## 实施前验收

- 无证据、只阅读、自述和重复作答不会获得虚假掌握分。
- 提示作答不会证明独立性；相同情境任务不会证明远迁移。
- 未知维度保持未知；关键门槛不会被平均值掩盖。
- 事件重放幂等，跨课程身份复用正确，目标/模型版本变动可追溯。
- 用独立后测与延迟复测衡量校准误差、预测误差和区间覆盖，分别检查新手、进阶学习者及各学科。
- 先在离线数据和内部试验中确定参数，再小范围呈现，验证用户能分清掌握估计、证据置信度和课程完成进度。

建议顺序：整理证据质量与身份 → 离线估计及校准 → 内部维度面板 → 用户可见百分比与解释 → 自适应验证任务。本次只交付此设计，不改动线上评分。
