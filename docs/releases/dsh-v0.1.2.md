# 好会学 DSH 插件 v0.1.2

为 npm 分发和插件市场索引整理安装说明与包元数据，学习功能沿用 v0.1.1。

- 包名保持 `@xue-learn/dsh-plugin`，公开发布目标为官方 npm registry。
- 增加项目主页、作者与公开发布配置，保留中英文显示标题「好会学」，补全英文功能描述。
- 更新 npm 安装和升级说明，并说明 npm 发布与自定义插件市场收录分别进行。
- v0.1.1 的 GitHub 归档保持不变；v0.1.2 使用独立版本与归档校验值。

在 DSH 插件管理器中输入 `@xue-learn/dsh-plugin@0.1.2`。也可以完全退出 DSH 后执行：

```sh
dsh plugin --profile desktop add @xue-learn/dsh-plugin@0.1.2
```

重新打开 DSH，在侧栏选择「好会学」。从已有插件升级时使用原有 DSH profile 和 `config.dataPath`，以继续使用课程、练习与阅读位置。模型与密钥由 DSH 管理。

适配 DSH `0.2.1-rc.5`，Node.js 要求 `>=24.9.0`。安装需要下载适合本机系统和架构的生产依赖。当前构建与自动验证平台为 Apple 芯片 macOS，其他平台尚未验收。此版本不新增桌面端 PDF 导出、Python 执行或隔离实验运行环境。

npm 发布不代表已被任何插件市场收录。市场维护者合并索引条目后，使用该索引的用户才能在「发现」中浏览和安装。
