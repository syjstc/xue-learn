# 好会学 DSH 插件 v0.1.1

在 DeepSeek Harness 中使用好会学的学习空间、目标规划、课程阅读、演示、追问与练习，无需另开好会学桌面应用。

- 复用桌面端的目标创建、课程目录和右侧学习助手，支持学习空间与完整课程位置恢复。
- 文字生成跟随 DSH 当前默认模型；模型配置与密钥由 DSH 管理，课程生成关闭思考模式。
- 模型调用记录写入 DSH 原生会话存储，保留请求、流式输出、工具关联、用量和结束状态。
- 阅读内容通过已认证的流式连接逐步呈现，学习数据保存在插件独立工作区中。
- 插件状态接口与运行时版本读取同一份包版本，避免升级后仍显示旧版本。

下载附件 `xue-learn-dsh-plugin-0.1.1.tgz`，在 DSH 插件管理器中使用文件的绝对路径安装。也可以完全退出 DSH 后执行：

```sh
dsh plugin --profile desktop add /absolute/path/to/xue-learn-dsh-plugin-0.1.1.tgz
```

重新打开 DSH，在侧栏选择「好会学」。升级时使用原有 DSH profile 和 `config.dataPath`，以继续使用已有课程、练习与阅读位置。

适配版本为 DSH `0.2.1-rc.5`，Node.js 要求 `>=24.9.0`。安装过程需要下载适合本机系统和架构的原生依赖。此次提供 GitHub 插件归档，没有发布到 npm 或插件市场。

当前构建和自动验证平台为 Apple 芯片 macOS；其他平台尚未验收。独立桌面端的 PDF 导出、Python 执行和隔离实验运行环境尚未在插件开放。图片、语音、联网搜索等能力需要单独配置，DSH 的文字模型密钥不会自动用于这些能力。
