# XueLearn 0.3.3 · 好会学

- English, Simplified Chinese and Traditional Chinese interfaces, with system-language detection and a language selector available before model setup.
- Saved language choices survive restarts and unrelated settings changes. Learning requests and status messages follow the active interface language; saved course content keeps its own language.
- Localized learning controls, practice, sync, PDF export, demonstrations and error messages. Added translation-key and parameter checks to CI.
- [English user guide](https://github.com/syjstc/xue-learn/blob/main/docs/user-guide.en.md), [中文使用指南](https://github.com/syjstc/xue-learn/blob/main/docs/user-guide.md), and bilingual README and privacy notes.

界面支持简体中文、繁體中文和英文，默认跟随系统语言。首次配置前即可切换语言，选择保存在本机工作区。修复界面语言与后台请求语言不一致，以及旧数据库默认值覆盖语言选择的问题；切换界面不会改写已有课程。

Model services require your own configuration and may charge for usage. Knowledge-search models are downloaded during setup. This source update does not publish an installer automatically.
