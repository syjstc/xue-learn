# 好会学 0.3.1

从学习目标出发，规划路径，通过阅读、交互演示、追问与练习逐步理解。

- 支持多家模型服务商和通用 OpenAI 兼容服务，实时读取可用模型，也可手动填写模型 ID。
- 阅读时可选中文本追问，保留内容位置；自动准备当前小节的后续内容。
- 改善交互演示的焦点、主题和布局，以及生成过程中的错误恢复。
- 更新存在已知安全问题的运行和构建依赖，统一校验桌面原生接口的调用来源。
- Core 与 Desktop 使用同一源码工作区，安装包包含应用、本地服务和所需运行资源。

macOS Apple 芯片版使用 Developer ID 签名及 Apple 公证。打开 DMG，将「好会学」拖入「应用程序」后运行。

应用不附带 API Key 或模型调用额度。模型服务需自行配置，可能按用量计费；知识检索模型在首次配置时按需下载。学习记录保存在本机，使用外部服务时相关输入会发送给所选服务商。
