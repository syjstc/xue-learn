选择与你的 Mac 架构一致的 DMG：`arm64` 为 Apple 芯片，`x64` 为 Intel。以实际附件为准。

这是私有仓库中的内部预览。应用和 DMG 均须通过 Developer ID 签名、Apple 公证、票据装订及 Gatekeeper 检查后，才开放下载；具体状态和校验和见附件 `release-manifest.json`、`SHA256SUMS`、`notarization.json`。

模型服务可能按用量计费。应用不包含 API Key，知识检索模型在首次配置时按需下载。
