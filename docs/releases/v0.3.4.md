# 好会学 0.3.4

- 提供简体中文、繁體中文和 English 界面，支持跟随系统、首次配置前切换，以及保存语言选择。
- 创建学习目标时展示当前进度、学习范围与路线预览；首模块准备完成后可以先开始学习，后续模块继续在后台准备。
- 改善中断和重试后的计划恢复、基础衔接与模块修订；后续审核失败时保留已经可学习的模块。
- 统一诊断问题卡片，改善阅读追问的跨段高亮、图片与演示布局，以及公式推导的排版。
- 修复演示兼容处理导致课程生成工具无法建立的问题。
- 同步更新 Core 至 0.3.48。另提供 [DSH 插件 0.1.1](https://github.com/syjstc/xue-learn/releases/tag/dsh-v0.1.1)：在 DeepSeek Harness 内使用共享学习界面、宿主默认文本模型和原生调用日志。

本次桌面安装包面向 Apple 芯片 Mac。模型服务需自行配置，可能按用量收费；应用不附带 API Key 或额度。项目仍在早期，学习内容与生成结果需要自行核对。

English: This update adds persistent English and Chinese interfaces, clearer goal progress and roadmap previews, earlier access to the first prepared module, safer background repair and resume, and improvements to reading follow-ups and teaching displays. DSH 0.1.1 is distributed separately. The desktop installer targets Apple silicon macOS.
