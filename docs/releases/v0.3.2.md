# 好会学 0.3.2

好会学帮助你把想学的问题变成学习路径，按小节阅读讲解、追问和练习。

- 新增面向普通用户的[使用指南](https://github.com/syjstc/xue-learn/blob/main/docs/user-guide.md)，覆盖安装、首次配置、创建学习目标和日常学习。
- 统一正式 Mac 安装包的构建与发布流程，核对安装包内应用、源码提交、签名、公证和上传后的文件校验值。

macOS Apple 芯片版使用 Developer ID 签名及 Apple 公证。打开 DMG，将「好会学」拖入「应用程序」后运行。

模型服务需自行配置，云端服务可能按用量计费；知识检索模型在首次配置时按需下载。学习记录保存在本机，使用外部服务时相关输入会发送给所选服务商。
