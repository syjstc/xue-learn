# 好会学使用指南

好会学是一款在电脑上使用的 AI 学习应用。告诉它你想学什么、现在会多少、希望学到什么程度，它会帮你整理学习路径，再带你按小节阅读讲解、看演示、提问和练习。

例如，你可以说：“我没有统计学基础，想看懂新闻里的平均数、概率和相关性。请多用生活中的例子，每天学一点。”

## 先了解怎么用

一次学习通常这样进行：

**说出想学的内容 → 确认学习要求 → 生成学习路径 → 开始第一课 → 边学边问 → 做练习 → 下次继续或复习。**

想系统学习一个主题，可以创建“学习目标”；想先弄懂一个较小的问题，可以选择“轻课”。资料可以在创建时添加，也可以先从一句话开始。

首次使用需要连接模型服务。好会学不附带云端模型额度，你需要使用自己的模型服务账号和 API Key。API Key 是服务商提供的调用密钥，相当于让应用使用该服务的凭证，不是你的登录密码。云端服务可能按用量收费，聊天网站的会员与 API 额度也可能分开计算。

## 1. 安装并打开

目前提供的是 **Apple 芯片 Mac 版**。在 Mac 的苹果菜单中打开“关于本机”，显示 Apple M 系列芯片的电脑可选 `mac-arm64.dmg`。

1. 打开[下载页面](https://github.com/syjstc/xue-learn/releases)，找到要安装的版本。
2. 下载名称以 `.dmg` 结尾的安装包。
3. 双击打开，把“好会学”拖到旁边的“应用程序”文件夹。
4. 从 Mac 的“应用程序”中打开“好会学”。

下载页面中的 “Source code” 是源码，安装应用请选择 DMG。使用安装包不需要安装开发工具。

## 2. 完成首次准备

第一次打开时，应用会带你完成两步准备。已经配置过的电脑可以沿用原来的设置。

### 连接学习助手

学习助手负责规划学习路径、编写讲解和回答问题。

1. 在“连接学习助手”中选择你有账号的模型服务商。
2. 点击“获取 API Key”，或到该服务商的官方平台创建密钥，再粘贴到应用里。
3. 点击“读取可用模型”，从返回的列表中选择一个模型。
4. 点击“保存并继续”。看到“模型服务已保存”后，进入下一步。

如果服务没有提供模型列表，点击“手动填写模型 ID”，复制服务商提供的准确名称。选择“通用 / OpenAI 兼容服务”时，还需要填写服务商给出的 API 服务地址。

API Key 保存后会在这台 Mac 上加密存储。不要把它放进学习内容、问题反馈或截图里。以后可以从应用的本机设置进入“快速开始”，更换服务或模型。

### 准备知识检索

知识检索帮助应用查找、关联你的课程和学习资料。它与上一步负责讲解的模型用途不同，两步都完成后才能进入学习。

1. 在“准备知识检索”中使用默认的本机 Qwen 方案。
2. 选择下载地址：中国大陆网络可选择 ModelScope，其他网络也可选择 Hugging Face。
3. 点击“下载并使用 Qwen”，等待下载和校验完成。当前界面显示的模型大小约为 639 MB，请预留空间并保持网络连接。
4. 应用准备好后，进入学习页面。

这个模型下载后在本机运行，不需要另外的 API Key。它负责检索；如果你的学习助手连接的是云端服务，生成讲解和回答问题时仍然需要网络。

语音、配图和联网搜索可以以后按需开启，首次使用时无需全部配置。已经在使用 Ollama 或在线知识检索服务的人，也可以展开“其他知识检索方式”进行选择。

## 3. 创建第一个学习目标

1. 在侧边栏点击“新建目标”；第一次使用时也可以从创建首个目标的提示进入。
2. 选择“学习目标”或“轻课”。第一次可以先选一个范围较小的主题。
3. 写下想学的内容。尽量说明**现在的基础、想解决的问题、希望达到的程度**。
4. 有自己的教材或笔记时，可以拖入 PDF、Word、TXT 或 Markdown 文件；也可以填写公开网页链接。
5. 点击“开始规划”。轻课会显示对应的创建按钮。
6. 按助手的提问补充要求，检查它整理出的学习安排，再确认创建。
7. 等待页面显示准备进度。第一课就绪后，点击“开始第一课”。

可以直接试用这段描述：

> 我是零基础，想学会用 Python 整理日常表格。请从最基本的概念开始，多给小例子，每次学习约 20 分钟。

创建课程和生成内容需要调用模型，耗时取决于主题范围、模型和网络。页面还在显示准备进度时，可以等待当前步骤完成；遇到错误时使用“重试创建”，避免反复新建相同目标。

## 4. 跟着课程学习

进入一课后，先看这一课的主题，再阅读当前小节的内容。

- **阅读讲解**：按正文顺序理解概念和例子。部分图示会在正文出现后继续补齐。
- **查看演示**：遇到图示、推导或交互演示时，按页面按钮逐步查看；需要更大区域时可进入专注模式。
- **不懂就问**：选中不理解的文字，再使用出现的追问入口；也可以打开“学习助手”直接提问。比如“请换一个生活中的例子”“这一步为什么成立”。
- **检查理解**：遇到自测或练习时先自己作答，再看反馈和解析。
- **继续下一步**：学完当前部分后，按页面上的“完成并继续”等提示推进。需要先完成练习的地方，按提示完成后再继续。

图示单独失败时，可以使用“重试组件”，其余正文仍可阅读。看到“正在生成正文”或“图示正在补齐”时，不需要重新创建课程。

讲解和练习由 AI 生成，可能出现错误。对拿不准的结论，可以让助手说明依据，并与原教材或可靠资料核对。

## 5. 下次接着学，以及复习

退出后重新打开应用，从侧边栏找到原来的目标，点击“继续学习”接着学，不必再创建同一个目标。也可以点击“查看完整课程”，打开目录回看已经学习过的小节。

从侧边栏进入“复习”，查看“待复习”中的内容，按提示进行主动回忆和测验。“主动复习”区域也可以选择已有单元练习。刚创建目标、尚未积累学习记录时，没有待复习内容是正常的。

可以把日常使用安排成：先完成一小节，再用几分钟做练习；下次打开时先看复习，再学新内容。

## 6. 按自己的习惯调整

| 想做的事 | 去哪里操作 |
| --- | --- |
| 换模型服务、更新 API Key | 本机设置 → 快速开始 |
| 开启语音、配图或联网搜索 | 快速开始中的其他服务与高级设置 |
| 修改学习背景或已有经验 | 设置中心 → 个人资料 |
| 调整教学风格 | 设置中心 → 教学助手 |
| 切换主题 | 设置中心 → 外观 |
| 回看某个主题 | 侧边栏选择目标，再进入课程目录 |
| 巩固学过的内容 | 侧边栏 → 复习 |

语音、配图和联网搜索可能使用独立的服务与额度。开启前先查看页面说明；已有课程不会因为更换服务商而自动全部重新生成。

## 常见问题

### 模型列表读不出来，怎么办？

先确认服务商选择正确、API Key 完整、账号有对应权限和可用额度，再检查网络。如果使用通用服务，还要核对 API 服务地址。没有模型列表的服务可以手动填写模型 ID；“保存成功”表示配置已经保存，实际能否生成还取决于服务商是否接受请求。

### 已经保存模型，为什么还不能开始学习？

检查第二步“准备知识检索”是否完成。只保存学习助手的配置，还没有完成全部准备。

### 知识检索模型下载失败，怎么办？

检查网络和剩余空间，可以更换下载地址后点击“重新下载”。等待校验和准备完成后再开始学习。

### 内容生成很慢，或者中途失败，怎么办？

先看页面是否仍在显示进度。若已提示失败，检查模型服务的网络、额度和模型名称，再使用页面里的重试或继续生成入口。重新生成会再次调用模型，可能产生新的用量。

### 学习记录会自动出现在另一台电脑吗？

默认保存在当前电脑，安装同一个应用不会自动同步记录。跨电脑使用需要另外配置同步。卸载应用也不等于清除全部学习数据；更换电脑或清理数据前，先备份重要内容。

### 导入资料后，资料会发到哪里？

资料和学习记录保存在本机。使用云端学习助手时，与当前任务相关的提问、课程内容或资料片段可能会发送给所选服务商。本机知识检索不代表所有 AI 功能都在本机运行，详见[数据与隐私](privacy.md)。

### 更新应用怎么做？

退出好会学，从[下载页面](https://github.com/syjstc/xue-learn/releases)下载新版本，再按安装步骤替换“应用程序”中的旧版。更新前先备份重要学习数据。
