# 数据与隐私

[English](privacy.en.md) · [简体中文](privacy.md)

好会学把学习记录、导入资料和设置保存在本机工作区。API Key 通过系统提供的加密能力保存在本机；安装包不附带开发者密钥、学习记录或检索模型。

使用 AI 生成功能时，应用会把完成该功能所需的问题、对话、相关学习内容或所选文档发送给你配置的模型服务商。启用联网搜索、图片或语音服务时，相应输入会发送给所选服务。各服务的收费、留存和使用条款由服务商决定。选择本机 Ollama 等服务时，仍需确认该服务自身的运行和联网配置。

首次准备本机知识检索时，应用会从你选择的 ModelScope 或 Hugging Face 下载模型。模型另行下载，不随 DMG 分发；使用前请查看模型自身的许可。检索本身在配置的检索环境中运行。

诊断日志可能包含请求和生成内容。分享日志、问题复现或工作区之前，请移除密钥、私人文档和可识别个人的信息。删除源码目录或卸载应用不会自动删除本机学习工作区；整理数据前请先备份需要保留的内容。

可选同步和扩展具有各自的数据访问范围。安装可执行扩展会允许其使用当前系统账户的原生能力，请仅安装可信来源的扩展。
